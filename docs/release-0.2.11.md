# 0.2.11 — 当日日报按主题复用

## 行为约定

同一天生成时，先按主题查找当天所有未进入回收站的日报，不再只看最后一份。对每个关注范围相同的主题选取可用条目最多的一份；数量相同时优先较新报告。保留原有提炼内容和引用链接，仅检索新增、无可用内容或关注范围实质改变的主题，然后合成为当前启用主题的双语日报。

- 新增 B：复用 A，仅搜索 B。
- 停用／删除 B：重组剩余主题，不搜索 A；重新启用 B 时，可从当日早期报告恢复 B。
- 调整顺序、界面语言、模型或最低条数：不会使已有主题重新搜索。旧主题不足新条数时如实标注不足，不补造内容。
- 英文缺失：仅补译；侧车快照丢失／损坏：优先恢复 HTML 内嵌快照，再尝试旧 HTML 的正文与来源。
- 主题描述、名称或国内外范围实质改变：仅重新检索该主题；跨天仍生成新日报。
- 内容为空、来源引用无法恢复的主题需要检索；不会从回收站恢复用户已删除文档。

## 实现与约束

`main/daily-reuse.js` 是本地与远程任务共享的复用入口，统一做日期、主题范围、引用归属和双语完整性检查。`report-snapshot.js` 负责旧版本兼容；`generation-service.js` 仅把 search 集合交给检索／提炼模块。失败时原日报保持不变。

本地通过 SQLite 查询当天所有有效日报。remote-DSA 将客户端快照与服务端同用户同日期缓存合并；确认领取后仍删除完整任务报告，但另保留最多 26 小时的主题缓存，单份最多 8 MB、100 个主题，定期清理过期记录。缓存按账号隔离，访问仍经过登录和订阅校验，不跨用户复用。云端并发任务若主题不同，明确返回 TASK_RUNNING，避免误用旧任务。

## 验证

Windows 全量回归：119 项单元／集成测试通过，界面、单实例、任务栏、存储、汇聚、模型配置、订阅等原有 UI 回归通过。新增测试覆盖同日增删／恢复主题、部分条目复用、调整最低条数、快照损坏恢复、翻译补齐、范围修改与跨日，以及云端领取后的增量检索、账号隔离和缓存过期。
