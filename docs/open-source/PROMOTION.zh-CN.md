# Daily AI：把追资讯的时间，留给真正重要的事

AI 发展太快，你是否也曾收藏了几十篇文章、加入了十几个信息群，却还是说不清今天真正值得关注的进展是什么？

**Daily AI 是一款本地优先的智能资讯桌面应用，围绕你的关注主题检索、核验与提炼，把分散的信息变成有重点、有来源、能积累的双语日报。**

每天都有新模型发布、新论文上线、新工具刷屏。问题早已不是没有信息，而是信息太多：同一件事被反复转述，真正相关的研究夹在热闹的标题里，等你抽出时间阅读，收藏夹又积了一层灰。

我们希望 Daily AI 帮你完成这件持续、琐碎却重要的事。你只需要告诉它关心什么：AI 智能体、大模型、无监督视觉、工业制造，或者你的专业方向。它会围绕主题规划查询，结合公开搜索、学术资料、开源社区和其他可访问渠道寻找线索，再把重点整理出来。

不是只把链接堆在一起。一份值得读的日报，应当让你尽快看清：发生了什么，为什么值得关注，原始证据在哪里。Daily AI 按主题组织内容，提炼重点，保留来源与日期，并结合近期已推送记录减少重复。你还可以设置国内或全球资讯偏好，让检索更贴近自己的工作。

早上打开软件，先读最新日报；想深入，再点开原文。新报告预先包含中英文内容，阅读时切换语言不用重新等一次翻译。每天、工作日或指定星期更新，都可以按自己的节奏设置。本地模式需要电脑与应用保持运行，网络和模型服务也会影响完成时间。

读过的信息不必再次散落。日报以 HTML 保存在本地，支持多标签阅读、月份查询、搜索与收藏。积累一段时间后，可以选日期生成浓缩汇聚，把零散进展串成一份阶段总结。回收站和保留策略则帮你管理文档数量，让积累不等于堆积。

你也可以决定怎样使用模型：配置自己的 API Key，选择适合的厂商与模型；或者使用另行提供的订阅服务。主题、报告和本地管理体验保持连贯，不必为了换一种调用方式重新学习软件。本地优先也不意味着离线：搜索和云模型仍需要联网，相关输入会发给对应服务。

还有一个我们想公开分享的特点：**Daily AI 完全基于 vibe coding 开发。** 从自然语言需求、界面设计，到代码实现、问题修复与测试，项目在与 AI 的协作中不断迭代。但 AI 写代码并不意味着可以省略验证。真实使用反馈、可复现问题和人工判断，仍是改进这个产品的基础。

我们正在准备开放主应用、local-DSA 和公共搜索与模型核心的源码，让更多人能理解它、改进它，甚至把它用于自己的信息工作流。remote-DSA 与安装程序不在开放范围；仓库地址和许可证将在确认后公布。

它不会承诺搜尽所有信息，也不会为了凑够条数编造内容。我们更希望它成为一个可检查、可改进的工具：让你少一点反复刷消息的疲惫，多一点理解进展、做出判断的时间。

**让信息每天来找你，把注意力留给创造。**
