# 常见问题

**一定要登录吗？** 本地 API Key 生成不需要登录。订阅与远程分享需要服务账号和相应权限。

**开源是否意味着免费模型？** 不意味着。模型和搜索可能产生第三方费用；托管订阅另行提供，价格由远端返回。

**为什么刷新不到模型？** 先填写并保存有效 Key，再检查 API 地址、权限和网络。部分厂商列表受账号限制，可手填厂商给出的模型 ID。

**为什么主题条目不足？** 日期窗、概念表达、来源可访问性和证据标准共同影响结果。系统应补充查询并说明缺口；请附遗漏的真实原文帮助改进，不能用虚构内容达标。

**为什么不是所有请求都用 MCP？** 通用 MCP 搜索与辅助新闻、学术、原文获取组成检索链路。MCP 是工具连接方式，不保证内容全面或正确。

**能关机后继续生成吗？** local-DSA 不能；托盘常驻仍可工作，彻底退出停止。远端计划取决于服务状态与权限。

**会重复推送吗？** 近 7 天指纹库降低重复风险，但 URL 变化、同一事件不同报道和语义差异可能影响判断。

**切英文会再次调用模型吗？** 新报告预先包含双语内容，可直接切换；历史缺少译文的报告可能需要补译。

**为什么迁移后要重新填 Key？** 系统安全存储可能绑定原用户或机器。不要用明文导出密钥解决迁移。

**Ubuntu 可以直接使用吗？** 目标是 Ubuntu 22.04+，当前验证主要是 Windows；Linux 完整支持需要独立验收。

**可以自己部署 remote-DSA 吗？** 远程实现不在公开范围。公开主应用与 local-DSA 的构建不应要求其源码。

**应该发布哪个源码包？** 使用名称含 public 的独立源码包，或本目录内容；历史内部 Source ZIP 不在本库范围，不能混入。许可证等发布信息仍需所有者确认。
