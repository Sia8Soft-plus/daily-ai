# 使用指南

[English](USER_GUIDE.en.md) · [文档中心](README.md)

## 首次使用

从可信的正式发布入口获取应用 ZIP，完整解压后启动 Daily AI.exe。不要只复制 exe，旁边的资源也是应用的一部分。公开下载请访问 [Daily AI 官网](https://www.ai4indus.com/daily-ai/)；当前以 Windows 验证为主。

在设置中选择生成方式。本地 API Key 模式不要求登录；订阅模式需要登录并由远端确认权限。套餐、价格、周期与状态由服务端返回，注册或登录不等于购买套餐。

## 配置模型与主题

先选择厂商和 API 地址，填入 API Key，再刷新可用模型并验证连接。模型列表取决于厂商接口与账号权限；可按厂商提供的 ID 手工输入。不要把密码当作 API Key。连接成功不代表有足够配额完成整次检索与生成。

默认主题为「AI 智能体与大模型」。可新增、编辑、启停、永久删除主题，包括修改默认主题的描述。建议描述关注对象、进展类型和排除项，例如“无监督、弱监督和半监督视觉学习，优先顶会论文，关注方法与实验结果”。

每主题可配置国内／全球偏好与最低条目目标，默认 6 条。条目目标驱动补充检索；无法证实的内容不应硬凑。冷门研究的近期更新较少时，请留意报告标注的时间范围和缺口。

## 生成与计划

立即生成后，右下角显示实际任务阶段。可折叠进度，展开查看或取消任务；中断需要向执行进程传播，不应把关掉提示当作任务已经取消。

同一天、同主题配置的已有结果会触发重复生成提示；主题变动时可复用符合条件的当日缓存，仅补查变化主题。缓存缺失或失效会重新检索。

更新计划支持每日、工作日和每周指定日期。默认每天 09:00，本地调度提前约 10 分钟启动准备；网络、模型和系统休眠可能导致延迟，计划时间不是严格服务时限。最小化到托盘可继续运行，彻底退出或关机会停止本地任务。云端计划取决于订阅服务配置。

## 阅读、收藏与清理

首页进入最新日报。左侧按月份浏览、搜索标题或内容，点击文档在顶部打开标签；收藏夹集中查看收藏。报告支持主题分区与来源链接，新生成的双语内容可跟随应用语言切换。

不需要的日报移入回收站，可恢复或清空。收藏和汇聚文档不参与默认过期清理；默认普通文档保留 6 个月。永久删除不可恢复，应核对确认范围。

在日期汇聚中选择有报告的日期范围，生成经模型提炼的汇聚文档；成功后原文档移入回收站。汇聚失败不应删除来源。需要长期保存的原文可先导出备份。

## 数据目录与分享

通过设置选择数据目录并执行迁移，等待完成后再拔出磁盘。迁移失败时保留原目录，先查错误再重试。备份应同时包含数据库与文档，运行中的 SQLite WAL 不能遗漏；跨系统或用户迁移后密钥可能需重新输入。

分享是主动操作，会把该文档 HTML 上传到远端。每篇文档管理一个有效分享链接，可撤销；持有链接的人可能访问内容。撤销不能收回他人已保存的副本，不适合保密报告。

亮／暗／跟随系统及中英文在设置中切换。遇到问题请看 [FAQ](FAQ.md)，勿提交包含密钥的截图或日志。
