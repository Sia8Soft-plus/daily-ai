# 完全基于 vibe coding 的项目

Daily AI 完全基于 vibe coding 开发：从自然语言需求与设计讨论开始，由 AI 协助生成代码、调整界面、调试和整理测试，再由真实使用反馈推动迭代。

这是一种开发方式的透明说明，不是质量认证。需求取舍、外部服务授权、许可证选择、隐私边界与发行决定仍由人负责。AI 生成的代码也可能存在遗漏、依赖错误、安全问题和未经验证的假设。

项目采用的改进循环是：描述可观察问题 → 阅读现有实现 → 提出可检查的改动 → 执行测试 → 验证实际行为 → 记录限制。不能把漂亮的页面或一次成功生成当作完整验收。

贡献中欢迎标明 AI 使用范围，不要求公布私人对话、凭据或内部数据。维护者和贡献者都应能够解释改动，保留失败案例，不伪造验证记录。

English: Daily AI is developed entirely through vibe coding. Natural-language requirements guide AI-assisted design, implementation, debugging and tests. Human judgment remains responsible for scope, security, permissions, licensing and release. AI authorship does not replace reproducible validation.
