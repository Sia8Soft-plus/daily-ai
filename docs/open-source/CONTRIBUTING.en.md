# Contributing

[简体中文](../../CONTRIBUTING.md)

Daily AI welcomes reproducible bugs, search-quality examples, UX improvements and documentation. Maintained by zkccpro, this public repository is licensed under MIT. Do not publish a mirror of the internal tree.

Read the [scope](SCOPE.md), [development guide](DEVELOPMENT.md) and [code of conduct](../../CODE_OF_CONDUCT.md). The remote service and installer are outside public contribution scope.

A bug report should include app version, OS, language, generation mode, minimal reproduction and expected/actual behavior. For retrieval issues, include the topic, date window, region preference and relevant public sources that were missed. Remove secrets and personal reports.

Keep pull requests focused. Explain the user-facing problem, resulting behavior, validation and limitations. UI changes need light/dark, Chinese/English and narrow-window checks. Update contracts when changing IPC or RPC. Preserve user data and verify cancellation, retry and shutdown behavior.

The project is developed entirely through vibe coding. AI-assisted contributions are welcome, but contributors remain responsible for understanding, attribution and testing. Never claim tests passed when they were not run. Contributions must be compatible with the MIT License; retain third-party attribution and submit only code you have the right to contribute.
