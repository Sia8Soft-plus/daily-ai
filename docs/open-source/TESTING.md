# 测试与质量基准

测试分为确定性回归、界面交互、真实检索评估及发行检查。模拟数据测试验证逻辑，不证明联网召回质量；Windows 结果不证明 Linux 可用。

## 本库测试命令

```bash
npm run check
node --experimental-sqlite --test tests/*.test.js
npm run verify:win
npm run audit:public
```

本库 verify:win 仅运行公开客户端与本地核心测试，不连接付费模型、不需要远程服务源码。local-DSA 启动测试会真正创建本机子进程，验证认证与 RPC；UI 使用独立模拟契约。真实联网质量测试应另行显式配置，可能付费。

## 必须覆盖的矩阵

| 领域 | 正常路径 | 边界与异常 |
| --- | --- | --- |
| 首次使用 | 无账号本地配置，登录后选择方式 | 无 Key、无订阅、会话失效 |
| 主题 | 新增／编辑默认及自定义主题 | 同义修改、空描述、删除、最小条目 |
| 模型 | 各厂商列表、手工模型、连接 | 未填 Key、权限、限流、空列表 |
| 生成 | 多主题、双语、增量 | 断流、取消、超时、部分主题不足 |
| 文档 | 标签、搜索、月份、收藏 | 空结果、大量文档、损坏文件 |
| 清理 | 回收、恢复、清空、保留期 | 收藏／汇聚豁免、重复点击 |
| 汇聚 | 日期选取与模型提炼 | 无文档、失败不删来源 |
| 账户 | 记住用户名、订阅详情 | 无套餐、过期、取消、切换用户 |
| 分享 | 单文档单有效链接 | 撤销、重复创建、上传失败 |
| 系统 | 托盘、单实例、通知、计划 | 休眠恢复、退出、任务栏固定启动 |
| 数据 | 迁移与统计 | 磁盘满、权限错误、回收站排除 |
| UI | 中英文、亮暗色、键盘 | 缩放、窄窗、弹窗层级、长文本 |

## 检索质量基准

固定一组可复现主题：大模型、无监督视觉、工业制造、时政、冷门跨学科、临时新主题。每个样本记录主题描述、目标时间窗、地区、最少条目、模型／搜索渠道及运行时间。人工提供一份公开可验证参考集合，不能用生成器输出本身当作真值。

评估主题召回覆盖、相关性、来源可追溯率、日期准确率、跨主题错配、近 7 天重复、证据不足说明、摘要可读性、成本与 p50/p95 时间。对不同厂商重复运行，控制网络与时间窗差异。最低条目达标率与事实可靠性分别计分。

不得以复制资讯或悄悄扩大时间范围换取达标。回归阈值应在建立基线后记录，不能在失败后临时降低。

## 结果记录

每次记录版本、平台、命令、通过／失败及未验证项。公开候选库的本轮验证见 [准备状态](../../RELEASE-READINESS.md)。本地模拟测试不等于真实检索质量验证，Windows 验证不替代 Ubuntu 验收。
